# n8n Documentation for Google Notebook LM

This directory contains the complete n8n documentation combined from the [n8n-docs GitHub repository](https://github.com/n8n-io/n8n-docs) in formats suitable for uploading to Google Notebook LM.

## Files

### 1. `n8n_documentation_with_toc.md` (RECOMMENDED)
- **Size:** 3.8 MB
- **Format:** Markdown with Table of Contents
- **Features:**
  - Comprehensive table of contents organized by category
  - All 1,232 documentation files combined
  - Organized by sections (API, Hosting, Workflows, etc.)
  - Markdown formatting preserved
  - Easy navigation with anchor links

**Best for:** Most users - provides organized, searchable documentation with clear structure.

### 2. `n8n_complete_documentation.txt`
- **Size:** 3.8 MB
- **Format:** Plain text
- **Features:**
  - All 1,232 documentation files combined
  - Sequential listing with file paths as headers
  - Simple text format

**Best for:** Users who prefer plain text or have issues with markdown rendering.

## How to Upload to Google Notebook LM

1. Go to [Google Notebook LM](https://notebooklm.google.com/)
2. Create a new notebook or open an existing one
3. Click "Upload source" or "Add source"
4. Select either:
   - `n8n_documentation_with_toc.md` (recommended)
   - `n8n_complete_documentation.txt`
5. Wait for the upload and processing to complete
6. Start asking questions about n8n!
